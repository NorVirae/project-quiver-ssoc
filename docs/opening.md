# Opening the bench and isolating equipment

**Your outcome:** check the work area and establish a safe state before touching hardware.

## Open the session

1. Read the job sheet and last handover. Confirm the assembly revision, task owner and outstanding defects.
2. Check the bench is dry, stable and clear. Put bags in the assigned location.
3. Inspect tools, plugs, leads and connectors. Report missing guards, exposed conductors or damage.
4. Prepare only the required items. Use a tray for fasteners and a suitable support for the assembly.
5. Identify every possible energy source. Confirm that propellers have been removed.
6. Agree the test or assembly method with the supervisor before starting.

## Isolate before changing anything

1. Announce that work is stopping. The authorised operator stops the equipment using its approved procedure.
2. Identify and disconnect each supply that can energise the work: flight battery, USB, bench supply, companion-computer supply and any other feed.
3. Prevent reconnection using the laboratory's isolation and tagging procedure. Label the assembly's state.
4. Follow the specified discharge time. A competent person verifies safe conditions at the approved test points.
5. Start work only when the supervisor releases the isolated assembly.

Never short a capacitor or terminals to discharge energy. A switched-off device may still be connected to a live supply. A disconnected battery still stores energy.

## Restart deliberately

Account for tools and loose parts. Check that cables, guards and connections are correct and everyone is clear. Only the authorised person removes the isolation tag and approves reconnection. Other teams must not alter the shared aircraft during a powered test.
