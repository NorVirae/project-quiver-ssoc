# Daily opening and closing checklist

Use a fresh record for each bench and session. The student completes the checks; the assigned checker or supervisor verifies the close.

## Before starting

- [ ] Signed in and permitted task confirmed.
- [ ] Last handover and outstanding defects read.
- [ ] Exit and access routes clear; work area dry and stable.
- [ ] Clothing and task protection correct.
- [ ] Tools, leads and equipment inspected.
- [ ] Parts and controlled tools issued and recorded.
- [ ] Supplies and isolation state identified.
- [ ] All propellers removed before bench work.
- [ ] Supervisor has released the task.

______________________________________________________________________

## Before leaving

- [ ] Approved shutdown completed or named handover accepted.
- [ ] Aircraft/circuit isolation state labelled.
- [ ] Tools and components counted and returned to labelled locations.
- [ ] Suspect items reported and segregated through the correct procedure.
- [ ] Work in progress labelled with owner, revision and restriction.
- [ ] Bench cleaned; waste sorted; walkways clear.
- [ ] Files saved and backed up; account locked or logged out.
- [ ] Missing items and unfinished work reported.
- [ ] Checker or supervisor accepts the bench; students sign out.
