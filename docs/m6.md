# M6 Software and simulation

**Deliverable:** a repeatable simulator setup and traceable software configuration.

## Prepare

Use the approved ArduPilot SITL workstation, source revision, model and parameter files. Your instructor will make sure proper flight controller firmware is installed. Keep a separate **Pix32 V6 hardware configuration record** for M4; simulator settings are not automatically suitable for Quiver hardware. Confirm the team storage location and preserve the issued baseline.

## Work sequence

1. Record software versions, source commits, launch commands and file origins.
2. Verify that the session connects only to the simulator.
3. Run the common take-off, hold, movement, return and landing exercise.
4. Save logs and record warnings, model assumptions and recovery actions.
5. Change one approved variable for an extension experiment, then restore the baseline.
6. Write instructions another student can follow on a second approved workstation.
7. Review any real-hardware configuration record with M4 and the integration lead.

## Stop and ask

Stop for an unexpected real endpoint, incompatible firmware target, unexplained warning or missing baseline. Do not bypass checks or send commands to shared hardware during another team's work. Add Quiver Hub or companion-computer integration only within the released scope.

## Acceptance checklist

- [ ] Versions, model, parameters and launch method recorded.
- [ ] Another student can reproduce the common exercise.
- [ ] Logs and model limitations are included.
- [ ] Changes and restored baseline are traceable.
- [ ] M4 accepts any hardware configuration interface.
- [ ] Files are backed up and credentials excluded.

## Show your understanding

Explain one observed behaviour using the log and distinguish a control setting from an assumption about the aircraft's physics.

**Submit:** setup instructions, configuration files, experiment record and logs. Each student must also operate the common exercise. The instructor accepts reproducibility; a successful simulated flight does not establish real flight safety.
