## Maintain the course

Keep the Markdown pages as the course source. Update the handbook and website together when a procedure, kit, room or software baseline changes. Record the change, responsible reviewer and effective date.

The website provides search, page navigation, print support and a handbook download. It is a documentation site, not a shared student-record database. Edit its Markdown files and rebuild to publish changes.
